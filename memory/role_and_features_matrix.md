# Complete Role-Based Feature Matrix

## User Roles

| Role | Type | Purpose | Scope | Key Permissions |
|------|------|---------|-------|-----------------|
| **Super Admin** | Staff | Full system control | Organization-wide | All permissions |
| **Admin** | Staff | Platform management | Organization-wide | Users, Forms, Training, Organization, Automation |
| **HRBP** | Staff | HR team management | Department-scoped | Employees, Training, Programs, 30/60/90 Plans |
| **Medical Approver** | Staff | Medical verification | Location-scoped | Medical review, approve, request resubmission |
| **Manager** | Staff | Team lead | Department-scoped | View team, manage plans, onboarding oversight |
| **Employee** | Employee | Self-onboarding | Personal | Own profile, complete forms, view training |

## Features by Module

### Dashboard
- **Analytics Dashboard** - View metrics, trends, completion rates
- **Admin Dashboard** - KPI tiles, recent employees, joining timeline
- **Employee Home** - Onboarding progress, next steps, notifications

### Employee Management
- **View Employees** - Search, filter, export employee list
- **Employee Profile** - View complete onboarding journey, stages, submissions
- **Edit Employee** - Update profile information
- **Employee Import/Export** - Bulk operations

### Onboarding Stages
- **Medical** - Medical requirements, document upload, approval
- **Pre-Onboarding** - Forms, document submission
- **Orientation** - Session assignment, attendance, Zoom integration
- **Onboarding** - Forms, documents, conversation thread
- **Post-Onboarding** - Follow-up forms, feedback
- **30/60/90 Plans** - Milestone tracking, feedback, goal setting

### Forms & Assessments
- **Form Builder** - Create/edit/delete forms
- **Quiz Management** - Create quizzes with multiple choice, essay, file uploads
- **Survey Management** - Create surveys
- **Form Responses** - View submissions, track status
- **Export Form Data** - CSV export of responses

### Training & Learning
- **Learning Paths** - Create/edit training programs
- **Training Assignments** - Assign courses to employees
- **My Learning** - View assigned courses, track progress
- **Certificates** - View earned certificates
- **Quiz Taking** - Take quizzes, get results

### Medical Management
- **Medical Review Queue** - List of pending medical reviews
- **Medical Document Review** - View uploaded documents
- **Approve/Reject Medical** - Decision buttons with notes
- **Medical Requirements** - Manage requirements setup
- **Medical Export** - Export medical data

### Live Sessions & Zoom
- **Sessions Dashboard** - Upcoming sessions, registration
- **Create Session** - Schedule live sessions with Zoom
- **Session Registration** - Employees register for sessions
- **Attendance Tracking** - Mark attendance
- **Zoom Integration** - OAuth setup, auto-link generation

### Content Management
- **Knowledge Hub** - Create/manage articles and resources
- **Training Modules** - Create course content
- **Orientation Content** - Set up orientation curriculum
- **Presentations** - Upload PPTX and rich content

### System Configuration
- **Email Settings** - Configure sender, SMTP
- **Email Templates** - Customize notification templates
- **Email Logs** - Track email delivery
- **Email Statistics** - View email metrics
- **Zoom Integration** - OAuth credentials, test connection

### Organization Setup
- **Organization Settings** - Company info, structure
- **Department Management** - Org units, hierarchies
- **Branding & Appearance** - Colors, fonts, logos
- **Landing Page** - Portal CMS, hero banner, content blocks
- **Roles & Permissions** - Role matrix, custom roles

### Automation & Rules
- **Automation Rules** - Create conditional workflows
- **Stage Advancement Rules** - Auto-progress employees
- **Notification Rules** - Trigger emails and notifications

### User Management
- **Users & Roles** - View all staff users
- **Create User** - Add new admin/HRBP/medical approver
- **Edit User** - Update user roles, permissions
- **Delete User** - Deactivate users

### Compliance & Reporting
- **Analytics Dashboard** - Completion rates, bottlenecks
- **Data Export** - CSV export of all onboarding data
- **Audit Logs** - Track changes and approvals
- **Medical Report Export** - Extract medical data

### Personal
- **My Profile** - View own profile, change password
- **Notifications** - View messages and alerts
- **Messages** - Real-time chat with team
