Setup Instructions

  1. Go to Zoom App Marketplace
  2. Click "Build App" → "OAuth"
  3. Fill in the app details (name, short description)
  4. For "Redirect URLs", enter: {{ zoom_callback_url }}
  5. Accept terms and create app

In your Zoom app settings:

  1. Copy the Client ID from "App Credentials"
  2. Copy the Client Secret from "App Credentials"
  3. Copy your Account ID from "Basic Information"
  4. Paste them into the fields above

In "Scopes", add these permissions:

  • meeting:write:admin - Create meetings
  • user:read:admin - Read user info

  1. Fill in all the fields above
  2. Click "Test Connection" button
  3. You should see a success message
  4. If error, verify your credentials are correct
