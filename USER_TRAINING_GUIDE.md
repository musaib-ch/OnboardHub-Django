## 1. ADMIN GUIDE

### Dashboard Overview
The admin dashboard shows:
- Total employees by status
- Completion rate
- Medical approval rate
- Training completion
- 30/60/90 plan progress

### Managing Employees
1. Go to Admin > Employees
2. Click on employee name to view full profile
3. Profile shows all 7 onboarding stages
4. Each stage displays:
   - Status badge (pending, in_progress, completed)
   - Activities count
   - Progress percentage

### Creating 30/60/90 Plans
1. Go to Admin > Onboarding Plans
2. Click "Create Plan"
3. Select employee
4. System auto-generates default 30/60/90 milestones
5. Customize milestones as needed
6. Employee receives email notification

### Settings Configuration
Navigate to Admin > Settings to configure:

#### Portal Setup
- Portal URL (used in all email links)
- Email sender name & address
- Email footer text
- Test email button

#### Zoom Integration
- Enter Zoom OAuth credentials
- Client ID & Secret
- Account ID
- Host email
- Click "Test Connection" to verify

#### Email Management
- View/edit 15+ email templates
- Customize for company branding
- View email logs & statistics
- Track delivery rates

### Role Management
Admin can:
- Assign roles: super_admin, admin, hrbp, manager, employee
- Create custom roles
- Define per-role permissions
- Scope HRBP access to departments

## 2. HRBP GUIDE

### Your Dashboard
As HRBP, you see employees in your assigned department only.

### Employee Profile View
Shows all 7 onboarding stages:
1. Medical - document upload & approval
2. Pre-Onboarding - initial forms
3. Orientation - orientation sessions
4. Training - learning paths
5. 30/60/90 - milestone plans
6. Onboarding - onboarding forms
7. Post-Onboarding - review & feedback

### Creating 30/60/90 Plans
1. Select employee
2. Click "Create Plan"
3. Default milestones auto-populate (customize if needed)
4. Employee gets email: "Your 30/60/90 Day Plan"
5. Track progress with visual timeline

### Posting Feedback
1. Go to employee's 30/60/90 plan
2. Click on 30-day, 60-day, or 90-day phase
3. Scroll to "Feedback" section
4. Click "Add Feedback"
5. Employee receives notification

### Training Assignment
1. Go to Admin > Training > Assignments
2. Select learning path
3. Choose employees
4. Set start date
5. Employees receive enrollment email

### Messaging Employees
1. Click "Messages" in sidebar
2. Start new conversation
3. Search employee by name/email
4. Send message
5. Use @mentions to tag others

## 3. MANAGER GUIDE

### Viewing Your Team
1. Go to Admin > Employees
2. Employees are pre-filtered to your team
3. Click employee to see full onboarding profile

### 30/60/90 Plan Management
1. View all team plans (Admin > Onboarding Plans)
2. Click employee plan
3. See milestones for all 3 phases
4. Check off completed milestones
5. Post phase feedback/guidance
6. Employee sees notification

### Checking Medical Status
1. Go to Admin > Medical Review
2. See all employees with pending medical uploads
3. Click to review uploaded documents
4. Approve or request changes
5. Employee gets email notification

### Reporting
1. Go to Admin > Analytics
2. View employee completion rates
3. See stage-by-stage breakdown
4. Export to CSV for reporting

## 4. EMPLOYEE GUIDE

### Employee Home
On login, see:
- Current onboarding stage status
- Tasks for this stage
- Due dates
- Progress percentage

### Completing Medical Upload
1. Go to My Profile > Medical
2. Upload required medical documents
3. Click "Submit"
4. Medical team reviews
5. You receive approval/rejection email

### Completing Forms
1. Go to Forms section
2. Fill out required forms
3. Click "Save as Draft" or "Submit"
4. After submission, form is locked
5. You get confirmation email

### Attending Orientation
1. Go to Orientation
2. See list of sessions
3. Click "Register"
4. Receive Zoom link in email
5. Join session on scheduled date
6. Get attendance confirmation

### Training & Learning
1. Go to My Learning
2. See assigned courses
3. Click course to start
4. Complete lessons & quizzes
5. Get certificate on completion

### 30/60/90 Plan
1. Go to My Onboarding Plan
2. See 3-month timeline
3. Check off milestones as complete
4. Post progress updates
5. Manager gives feedback
6. Track overall progress %

### Messaging
1. Click "Messages"
2. See all conversations
3. Click to open chat
4. Type message
5. Use @mentions to tag users

### Profile Settings
1. Go to Profile
2. Update personal info
3. Set notification preferences
4. View notification history

## 5. FAQ

### Q: How do I reset a user password?
A: Admin > Users > Select user > Click password reset link

### Q: Can I create custom roles?
A: Yes! Admin > Roles > Create Custom Role. Define which permissions the role has.

### Q: Where are email logs?
A: Admin > Settings > Email > Email Logs tab

### Q: How do I export employee data?
A: Admin > Analytics > Click "Export to CSV"

### Q: Can HRBPs see employees outside their department?
A: No. HRBPs are scoped by department in role settings.

### Q: How do I test the Zoom integration?
A: Admin > Settings > Integrations > Zoom > Test Connection button

### Q: Can employees chat with external users?
A: No. Chat is internal only (registered users only).

### Q: What happens when an employee completes all stages?
A: Status changes to "completed", certificate is generated, record archived.

### Q: Can I customize email templates?
A: Yes! Admin > Settings > Email Templates. Edit subject & body text.

### Q: How often should 30/60/90 check-ins happen?
A: Recommended: Day 30 (initial review), Day 60 (progress), Day 90 (final assessment)
